# Tradutor de Legenda

App Android que lê a legenda do vídeo na tela, traduz para português e fala a tradução em voz alta, rodando em segundo plano por cima do YouTube e de outros apps.

- Leitura da tela: captura de tela do Android + ML Kit (OCR no celular)
- Tradução: ML Kit Translate (no celular, baixa o idioma na 1ª vez)
- Voz: TextToSpeech do Android em pt-BR

O APK é gerado automaticamente pelo GitHub Actions e fica em **Releases**.
